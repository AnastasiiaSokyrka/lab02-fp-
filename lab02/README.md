# Lab 02 - Parcel Delivery

## Мета роботи

Ознайомитися з функціями вищого порядку, lambda, map, filter, reduce та композицією функцій у Python.

## Опис програми

Програма виконує аналіз вартості доставки посилок.

Для кожної посилки зберігаються:

- `id` — ідентифікатор посилки;
- `sender` — ім'я відправника;
- `region` — регіон доставки;
- `delivery_parts` — складові вартості доставки.

Конвеєр виконує такі операції:

1. Нормалізація імен відправників.
2. Обчислення загальної вартості доставки.
3. Застосування коефіцієнта для вибраного регіону.
4. Фільтрація посилок за мінімальною вартістю доставки.
5. Сортування за вартістю доставки.
6. Формування Top-N посилок.

Для обчислення статистики використовується `reduce`:

- `count` — кількість посилок;
- `delivery_sum` — загальна вартість доставки;
- `avg_delivery` — середня вартість доставки.

Вхідні записи не змінюються під час обробки.

## Встановлення

Створити віртуальне середовище:

```bash
python -m venv .venv
```

Активувати його у Windows:

```bash
.venv\Scripts\activate
```

Встановити залежності:

```bash
pip install -r requirements.txt
```

## Запуск програми

```bash
python main.py
```

Приклад запуску з параметрами:

```bash
python main.py --top 2 --boost-region West --factor 1.1
```

Додаткові параметри:

- `--top` — кількість посилок у результаті;
- `--boost-region` — регіон, для якого застосовується коефіцієнт;
- `--factor` — коефіцієнт зміни вартості доставки;
- `--threshold` — мінімальна вартість доставки для фільтрації.
